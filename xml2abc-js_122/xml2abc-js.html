    Explanation of the options:
    
  • Unfold repeats: if checked (only works for simple repeats, not for nested repeats)
    • 
    
  • Bars per line: the number of bars on a line (positive integer, default 0 == no limit)
    • 
    
  • Characters per line: the maximum number of characters on a line. (positive integer, 
        default 100)
    • 
    
  • Credit filter level (0..6).
        Credits, if not fitered, are shown as T: lines in the ABC translation.
        
      
        
    • 0 (default): only show credits when no title is present in the xml-file
      • 
        
    • 1: show all credits
      • 
        
    • 2..6: skip if the credit already appears
        in title, composer or lyricist (a higher number skips less)
      • 
        
    
    
    • 
    
  • No volta on higher voice numbers: 0 (default),1,2,3,4
        
      
        
    • 0: add volta number(s) or text to all voices in all parts
      • 
        
    • 1: only volta in the first voice
      • 
        
    • 2: only volta on first voice of each part
      • 
        
    • 3: only add volta only to lowest voice in part 0
      • 
        
    • 4: only add volta to lowest voice in each part
      • 
        
    
    
    • 
    
  • Denominator unit length (L:):
        
      
        
    • 0: L-value is chosen that results in the shortest ABC text (per voice)
      • 
        
    • 1,2,4,8,16 or 32
      • 
        
    
    
    • 
    
  • %%midi options: 0 (no midi), 1 (only program), 2 (all midi)
    • 
    
  • No score line breaks: if checked
    • 
    
  • No pedal directions: if checked
    • 
    
  • All direcions to first voice: if checked, otherwise directions go into the voice where
        they are encountered.
    • 
    
  • Translate stem directions: if checked, otherwise ignore
    • 
    
  • perc, tab staff → %%voicemap: if checked generate %%map and %%voicemap in ABC code
    • 
    
  • Shift note heads in tablature: checkbox: shift note heads 3 units left
    • 
    
  • Measure numbers:
        
      
        
    • blank: no numbers
      • 
        
    • 0: number every system
      • 
        
    • 1..n: number every n-th measure
      • 
        
    
    
    • 
    
  • Page format, radio buttons: Copy from xml, No format, Specify:
        
      
        
    • scale: positive float (around 1.0)
      • 
        
    • page width: cm, positive float
      • 
        
    • left margin: cm, positive float
      • 
        
    • right margin: cm, positive float
      • 
        
    
    
    • 
    
  • Rebeam: make new beams on the beat of the time signature
    • 
    
  • Accidental rule selection: selects the rule set for the translation of microtonal accidentals.
        
      
        
    • Strict: respects floating point alter values when no accidental element present
      • 
        
    • Burak Uyar: when both alter and accidental are missing a natural is implied when
        the pitch is altered by the key.
      • 
        
    • MuseScore: only respects integer alter values.
        Ignores accidental rules for microtonal accidentals
      • 
        
    • Finale: ignores alter values.
        ignores accidental rules for microtonal accidentals
      • 
        
    
    
    • 
    
  • Temperament selection: selects the temperament for microtonal accidentals.
        
      
        
    • Force 53 means that edo36 accidentals will be mapped to edo53,
        even if it is a pure edo36 file.
      • 
        
    • Fractional edo36 will translate up/down accidentals as _1/3B and ^2/3F in stead of_1B and ^2F.
        The latter integer values are used for makam accidentals (edo53).
